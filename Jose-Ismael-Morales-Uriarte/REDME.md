# Mi primera app en Stellar

App web para el Entregable 1 del Pura Vida Bootcamp.

## Qué hace
- Permite conectar una wallet de Stellar (con Stellar Wallets Kit).
- Muestra la dirección pública conectada, me falla en algunos inicios.
- Muestra el balance de XLM en testnet.

## Cómo usé Stellar Raven
Conecté Raven como MCP y lo usé como asistente para elegir cómo integrar la wallet
y cómo consultar el balance de la cuenta, es algo complicado.

## Cómo correrla
    npm install
    npm run dev
