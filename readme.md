# Entregable 1 · Pura Vida Bootcamp

## Construye tu primera aplicación en Stellar usando Stellar Raven 

En este entregable vas a construir un producto básico en Stellar utilizando el MCP oficial de Stellar, **Stellar Raven**.

El objetivo es que pongas en práctica lo aprendido durante la clase 1: cómo consultar Raven, cómo utilizarlo como asistente durante el desarrollo y cómo aprovechar sus capacidades para construir una aplicación funcional en Stellar.

**MCP oficial:** https://raven.stellar.org/

## ¿Qué tienes que hacer?

Construye una aplicación básica sobre Stellar apoyándote en Stellar Raven durante el proceso de desarrollo.

No necesitas crear algo complejo. Lo importante es que experimentes con Raven, lo utilices como herramienta de apoyo y logres construir un producto que funcione.

¡Puedes desarrollar la idea que quieras!

## Requisitos mínimos

Conexión de wallet: La aplicación debe incluir una sección o apartado que permita al usuario conectar su wallet de Stellar.

## ¿Cómo se entrega?

Sigue estos pasos para completar tu entrega:

1. Haz un **fork** del repositorio oficial del bootcamp.
2. Crea una **carpeta con tu nombre completo** en la raíz de tu fork.
3. Dentro de esa carpeta, desarrolla y agrega tu aplicación.
4. Crea tu Branch, antes de comenzar a desarrollar, crea una nueva rama siguiendo esta convención de nombres:

`feature/tu-nombre`

**Ejemplo:**

`feature/kevin-latino`
5. Crea un **Pull Request (PR)** hacia el repositorio original.
6. En la descripción de tu PR, incluye tu **nombre completo** y adjunta una **captura de pantalla que demuestre que completaste el formulario de Embajadores Oficiales de BAF**.
