# Mi primera app en Stellar

App web básica que conecta la wallet Freighter y muestra la dirección y el balance de XLM en testnet.

Construida con ayuda de Stellar Raven (https://raven.stellar.org/).

## Cómo correrla
1. Instala la extensión Freighter y ponla en **Testnet**.
2. En esta carpeta: `python -m http.server 8000`
3. Abre http://localhost:8000
