Frontier Lab

Asistido por Stellar Raven MCP

Esta dApp fue diseñada y estructurada utilizando Stellar Raven (https://raven.stellar.org/), el Model Context Protocol (MCP) oficial creado por la Stellar Development Foundation (SDF).

⚡ Capacidades aplicadas:
  • Detección y conexión sin fricción con la extensión Freighter API.
  • Consumo directo de la API REST de Horizon Testnet para balances y transacciones.
  • Financiamiento automático de cuentas de desarrollo vía Friendbot.
